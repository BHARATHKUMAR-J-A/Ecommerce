How these work

These live in the database and take effect immediately — no restart, no code edit. Anything left at its default falls back to config.py.

Changing the default commission only affects sellers approved from now on, and only their future sales. Existing sellers keep the rate on their record, which you can change on the sellers page.

Shipping and tax are applied at checkout, so changing them here changes what the next customer pays but never rewrites an order already placed.
